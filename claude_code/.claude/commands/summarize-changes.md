1. Run `git log --oneline -20` to get the last 20 commits.

3. For each file that changed, briefly describe what the change does based on the diff.
4. Provide a structured summary with:
   - **Recent Activity**: a one-paragraph overview of what's been happening
   - **Files Changed**: a table of changed files with a one-line description each
   - **Key Decisions**: any architectural or design decisions visible in the diffs
   - **Open Items**: anything that looks incomplete or needs follow-up
