# Requirements Specification

**DocuQuery** is an internal document Q&A tool that allows employees to upload a text document (such as a policy, contract, report, or technical specification) and ask natural-language questions against it, receiving streamed, citation-backed answers in real time. The tool exposes a REST API (FastAPI) that handles document ingestion, multi-turn conversation sessions with explicit lifecycle management (create, summarize, persist, reset, expire), and integrates with the Anthropic Claude API using prompt caching so that repeated questions against the same document do not re-pay the full context cost. Responses conform to a validated JSON schema that includes answer text, source citations with section references and confidence scores, and session metadata. The infrastructure touches a Python backend (FastAPI + uvicorn), the Anthropic Messages API (streaming mode with cache_control), and in-memory session storage (production-ready for swap to Redis). "Done" means: a developer can start the server, upload any of the 5 sample documents via a POST endpoint, ask multiple follow-up questions with streamed responses that cite specific document sections, observe prompt caching in action via usage metrics, and read the configuration file to understand exactly which model version and prompt version are in use — all without needing a walkthrough of the codebase.
